# Wallhaven

Browse [wallhaven.cc](https://wallhaven.cc) and set your wallpaper, from any host.

A full wallpaper browser for the Ryoku desktop: search, filter by Latest / Top
week / Top month, page through results, and set any wallpaper with a click.

It renders as either:

- a **frame popout** that melts out of the screen edge on hover, or
- a **desktop widget** you drag onto the wallpaper alongside the clock and weather.

The same adaptive view is used in both - the shell owns the surface, motion, and
placement; the plugin only supplies the content.

Official Ryoku plugin. Install it from **Ryoku Settings -> Plugins -> Discover**.
