Full Audit is the "config 3" entry (configs/3.jsonc) from the community awesome-fastfetch-collection (https://github.com/Chintanpatel24/awesome-fastfetch-collection), MIT licensed, originally by LainOS. Ported for Ryoku: Logo changed from kitty-direct PNG glob to builtin Arch logo; added padding.right 2. Dropped de and lm from the system group (empty on Arch + Hyprland); wm is now the group's box closer. Dropped poweradapter, gamepad and bluetooth from the software group (no output on a stock Arch laptop). Per-module keyColor magenta/green/yellow replaced by display.color slots: keys #c678dd (system), title #98c379 via keyColor (software), separator #e5c07b via keyColor (hardware). Separator is two spaces, so routing hardware keys through the separator slot leaves the actual separator tint invisible. It ships as a single config file using only built-in Fastfetch modules, with no external runtime assets.
