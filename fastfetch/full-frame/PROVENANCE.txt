Full Frame is the "sofijacom-config" entry (configs/sofijacom-config/config.jsonc) from the community awesome-fastfetch-collection (https://github.com/Chintanpatel24/awesome-fastfetch-collection), MIT licensed, originally by sofijacom. Ported for Ryoku: Replaced the $(find ...) shell-substitution PNG logo with the built-in Arch logo, keeping a blue tint that matches upstream's blue logo color. Narrowed the outer frame to an equal 54-column width so the whole readout fits within 100 columns. Made all four frame rules equal width (upstream's rules were an uneven 60 vs 61 dashes). Upstream's per-module keycolor was a no-op (lowercase key) and the design shipped monochrome, so kept it uniform and routed one blue accent through display.color.keys. Kept the grey frame as ANSI palette {#90} (upstream used \u001b[90m). Shrank the trailing colors block (upstream block width 10) to a compact circle row to stay within 100 columns. It ships as a single config file using only built-in Fastfetch modules, with no external runtime assets. The preset now ships that design's own emblem (arch-mark.png): The Arch mark from the upstream config's png folder. It installs beside the config and is referenced from it; the artwork is redistributed as it appears in the upstream MIT-licensed collection and remains the property of its creators. Swap it in Settings -> Fastfetch, or delete the file to fall back to the built-in Arch logo.
