# The Ricer

Aether and the must-have apps for shaping the desktop, inspecting colors, editing visuals, and making the machine yours. A wallpaper-driven theme maker at the center, color pickers and converters, GTK and Qt appearance tools, an icon theme, screenshot annotation, a fast image viewer, font management, and a couple of terminal toys to show off the active palette.

## What it installs

| Tool | What it is | Source | Upstream |
| --- | --- | --- | --- |
| aether | GTK app that extracts a palette from a wallpaper and themes the desktop. | AUR | https://github.com/bjarneo/aether |
| gpick | GTK color picker for sampling colors and building palettes. | pacman | https://github.com/thezbyg/gpick |
| pastel | Command-line tool to generate, analyze, and convert colors. | pacman | https://github.com/sharkdp/pastel |
| imv | Keyboard-driven image viewer for Wayland and X11. | pacman | https://sr.ht/~exec64/imv/ |
| satty | Wayland screenshot annotation with arrows, text, blur, and crop. | pacman | https://github.com/gabm/satty |
| nwg-look | GTK settings editor for wlroots: theme, icons, cursor, and fonts. | pacman | https://github.com/nwg-piotr/nwg-look |
| qt6ct | Configuration utility for the appearance of Qt 6 applications. | pacman | https://www.opencode.net/trialuser/qt6ct |
| qt5ct | Configuration utility for the appearance of Qt 5 applications. | pacman | https://qt5ct.sourceforge.io/ |
| kvantum | SVG theme engine and manager for Qt applications. | pacman | https://github.com/tsujan/Kvantum |
| papirus-icon-theme | SVG icon theme with light and dark variants and folder colors. | pacman | https://github.com/PapirusDevelopmentTeam/papirus-icon-theme |
| font-manager | GTK app to preview, compare, and manage installed fonts. | pacman | https://fontmanager.github.io |
| cpufetch | Terminal CPU information with ASCII architecture art. | pacman | https://github.com/Dr-Noob/cpufetch |
| cmatrix | Curses scrolling Matrix-style screen animation. | pacman | https://github.com/abishekvashok/cmatrix |
| cbonsai | ncurses bonsai tree generator and screensaver. | AUR | https://gitlab.com/jallbrit/cbonsai |

Install it from **Settings, Extras, The Ricer, Install all**, or pick individual items. Anything already on the system is detected and skipped, so re-running only fills the gaps.

Routing: aether and cbonsai come from the AUR; everything else from the official repos. hyprpicker, wallust, and fastfetch already ship with Ryoku.
